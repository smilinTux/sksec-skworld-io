# sksec-skworld-io

The static landing page for [sksec.skworld.io](https://sksec.skworld.io), served via GitHub Pages
directly from this repository's `index.html` and `CNAME`.

sksec is SKWorld's edge security layer: CrowdSec (behavioral intrusion detection, crowd-sourced
reputation) plus a Traefik forwardAuth bouncer, deployed as the `core/sksec` role in the
[SKStacks](https://github.com/smilinTux/skstacks) sovereign infrastructure framework. A
companion optional role, `sksec-web`, adds a browser dashboard for it, SSO-gated by default. See
the [sksec README](https://github.com/smilinTux/skstacks/blob/main/v1/ansible/core/sksec/README.md)
and the [sksec-web pull request](https://github.com/smilinTux/skstacks/pull/226) in that repo for
the full technical reference this site is grounded in.

This site is part of the [SKWorld](https://skworld.io) sovereign AI ecosystem.
